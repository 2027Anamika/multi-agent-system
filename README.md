# 🔬 ResearchMind — Multi-Agent AI Research System

ResearchMind is an AI-powered multi-agent research assistant built using **LangChain**, **Mistral AI**, **Tavily Search**, and **Streamlit**.

The system uses multiple specialized AI agents that collaborate together to:
- search the web
- scrape detailed information
- generate a structured research report
- critique and review the final output

---

# 📌 Project Summary

ResearchMind is a modern multi-agent AI system designed to automate the research workflow.

Instead of relying on a single LLM response, the system divides responsibilities among multiple intelligent agents:

- A **Search Agent** gathers relevant and recent web information.
- A **Reader Agent** scrapes and extracts deeper insights from sources.
- A **Writer Chain** compiles a structured research report.
- A **Critic Chain** evaluates and improves the final output.

The project demonstrates:
- Multi-agent orchestration
- LangChain pipelines
- Tool usage in LLM systems
- AI-assisted research automation
- Beautiful Streamlit frontend deployment

This project is ideal for:
- AI engineering portfolios
- LangChain learning
- Research automation
- Agentic AI demonstrations

# 🧠 Architecture

The system consists of 4 AI components:

| Agent | Role |
|---|---|
| Search Agent | Finds relevant web information |
| Reader Agent | Scrapes and extracts detailed content |
| Writer Chain | Generates research report |
| Critic Chain | Reviews and critiques the report |
